# 区域康养平台模块详细设计 Prompt

你是高级系统分析师，请基于《沈阳市和平区全域综合养老服务项目（一期）信息化建设需求》输出《区域康养平台模块详细设计》文档，要求覆盖业务模块、对象模型、接口、状态流转、字段设计与异常处理。

## 一、设计背景

- 项目名称：沈阳市和平区全域综合养老服务项目（一期）
- 服务范围：龙湖邻里中心 + 31 个社区居家养老服务点位
- 一期重点：健康管理、服务呼叫、安全监控、运营管理、家属互动

## 二、输出要求

请输出完整 Markdown 文档，并按“模块 -> 子模块 -> 功能点”三级结构展开。每个模块必须尽量包含以下内容：

1. 模块目标
2. 适用角色
3. 业务说明
4. 功能清单
5. 页面/入口
6. 核心实体与字段
7. 关键接口
8. 状态流转
9. 规则校验
10. 异常处理
11. 日志与审计要求
12. 报表与指标

## 四、字段与接口设计要求

请对关键对象给出建议字段，例如：

- 老人档案
- 健康测量记录
- 服务呼叫单
- 告警事件单
- 员工排班记录
- 床位信息
- 餐饮计划
- 缴费账单

每个对象建议给出：

- 字段名
- 中文含义
- 类型
- 是否必填
- 示例值
- 备注

每类关键接口建议给出：

- 接口名称
- 请求方式
- 路径示例
- 请求参数
- 返回参数
- 调用方
- 幂等与鉴权要求

## 六、输出风格

- 文档必须工程化、细致、便于研发直接拆分任务

- 明确前后台边界
- 明确状态机
